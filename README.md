# Vehicle Borrowing System (ระบบยืม-คืนรถ)

ระบบจัดการการยืมยานพาหนะภายในองค์กร สำหรับ Odoo 18 พัฒนาโดย ittqs

## คุณสมบัติหลัก (Main Features)

1. **ระบบยืม-คืนรถ (Vehicle Borrowing)**: 
   - พนักงานสามารถตรวจสอบสถานะรถและทำเรื่องขอยืมผ่านหน้าเว็บไซต์
   - แอดมินสามารถตรวจสอบและอนุมัติคำขอผ่านระบบหลังบ้าน (Backend)
   - ติดตามสถานะการคืนรถและประวัติการใช้งาน

2. **ระบบจัดการอะไหล่ (Spare Parts Management)**:
   - จัดการคลังอะไหล่แยกตามโรงงาน (TQS, CKR, TPS)
   - ระบบแจ้งเตือน Stock ต่ำ (Low Stock Decoration)
   - บันทึกการรับเข้า (Receive) และการเบิกจ่าย (Issue) พร้อมเชื่อมโยงกับงานซ่อม

3. **ระบบจัดการการซ่อมบำรุง (Repair History)**:
   - บันทึกประวัติการแจ้งซ่อมของรถแต่ละคัน
   - ติดตามค่าใช้จ่ายและอะไหล่ที่ใช้ในการซ่อม

4. **ระบบส่งย้ายรถระหว่างโรงงาน (Vehicle Transfer)**:
   - Workflow การโยกย้ายรถระหว่างสาขา (TQS, CKR, TPS)
   - ระบบอนุมัติโดย Head Admin และการตอบรับโดยโรงงานปลายทาง

5. **การควบคุมสิทธิ์ตามโรงงาน (Multi-factory RBAC)**:
   - แยกสิทธิ์การจัดการข้อมูลอย่างชัดเจนตามสาขาของผู้ใช้งาน
   - **Head Admin**: อนุมัติการส่งย้ายและดูภาพรวมทั้งหมด
   - **Factory Admin**: จัดการอะไหล่และยานพาหนะในสาขาตนเอง
   - **Factory User**: ใช้งานระบบยืมรถในสาขาตนเอง

6. **รองรับหลายภาษา (Multi-language Support)**:
   - รองรับภาษาไทย (Thai), อังกฤษ (English) และพม่า (Burmese)

## การติดตั้ง (Installation)
